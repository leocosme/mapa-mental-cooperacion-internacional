# Mapa mental interactivo — Cooperación Internacional

Referentes teóricos y normativos de la cooperación internacional para el análisis contextual transnacional en la gerencia de proyectos (Maestría en Gerencia de Proyectos).

**Ver el mapa:** https://leocosme.github.io/mapa-mental-cooperacion-internacional/

Aplicación en un único archivo (`index.html`) hecha con HTML5, CSS3 y JavaScript sin dependencias. Incluye:

- Cinco ramas: teorías, modalidades, tipos, instrumentos jurídicos y actores en Colombia.
- Capa transversal «Cooperación Internacional + Gerencia de Proyectos».
- Buscador, filtros, zoom y arrastre, panel informativo, referencias y modo presentación (teclas 0–6, Esc).
- Diseño adaptable a escritorio, tableta y móvil.
